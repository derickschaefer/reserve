# v1.2.1 stopping point

RESERVE v1.2.1 is code-frozen at the workflow repository foundation. The CLI
changes are intentionally limited to local workflow examples, repository
boundaries, and the internal official repository descriptor.

## Frozen CLI scope

- Educational examples live under `examples/workflows/`.
- Personal workflows remain local under the `personal` namespace.
- The official repository is `reserve-workflows`.
- The CLI's permanent API base is `https://api.reservecli.dev/v1`.
- The CLI does not yet browse, install, update, publish, authenticate against,
  or execute remote workflows.

## Live API checkpoint

The separate `reserve-workflows-api` Cloudflare Worker currently provides:

```text
GET https://api.reservecli.dev/v1/health
GET https://api.reservecli.dev/v1/repositories/official
```

Health is public. The official repository descriptor currently uses the
temporary single Bearer-key bootstrap configured as the Cloudflare secret
`RESERVE_API_KEY`.

## Future direction

The API will evolve independently using curl and script-based tests. A public
workflow preview in v1.2.2 is aspirational and is not part of the v1.2.1 CLI
contract. Any future CLI integration must follow a separately reviewed and
stable API response contract.
