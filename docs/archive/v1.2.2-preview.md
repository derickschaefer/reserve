# v1.2.2 workflow API preview

v1.2.2 begins the read-only CLI integration with the official RESERVE workflow
API at `https://api.reservecli.dev/v1`.

## Commands

```text
reserve workflow browse
reserve workflow browse <collection>
reserve workflow get <collection> <workflow> [version]
```

These commands browse and retrieve published official workflow content. They do
not modify the local workflow store, install files, execute remote pipeline
content, or publish workflows.

The preview uses the permanent RESERVE API namespace and supports table and JSON
output through the existing global `--format` flag. It intentionally does not
use the FRED API key as RESERVE authentication.

## Deferred to v1.2.3

Authentication and enrollment follow [`API-AUTHENTICATION.md`](../../reserve-workflows-api/API-AUTHENTICATION.md):

- verified email enrollment;
- one-time FRED API-key validation;
- independent RESERVE token issuance;
- secure token storage, login, logout, revocation, and rotation;
- authenticated API enforcement and rate limits.

The v1.2.2 API preview is read-only and intentionally narrower than the final
authenticated workflow distribution model.
